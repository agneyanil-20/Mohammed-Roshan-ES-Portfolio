# Roshan E S portfolio

Responsive, buildless HTML/CSS/JavaScript portfolio. The deployable website is in `dist/`.

The red, black, and paper editorial art is an original visual interpretation of the supplied reference. Role illustrations are clearly labeled editorial summaries, not client deliverables. Content is drawn from the supplied CV and user corrections.

## Features

- Desktop and mobile layouts, responsive navigation, reduced-motion support.
- Experience category filters and accessible native dialogs with career details.
- Expandable expertise sections, email copy, mail and phone links, LinkedIn.
- Print-friendly resume with browser PDF saving.
- Self-hosted fonts and local assets; no external tracking or API dependency.

## Local preview

Serve `dist/` using any static HTTP server. No build step is required.

## Content

Edit `dist/index.html` for main content and `dist/script.js` for the role dialogs. Keep `dist/resume.html` synchronized with updated career details. User-supplied 2.5–5% conversion range is not attributed to a specific employer or represented as a percentage increase.

Hosting configuration is in `.openai/hosting.json`. Preserve its project identity.
